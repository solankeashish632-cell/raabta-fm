# RAABTA FM — free prototype

## Run it
Open `index.html` in a browser. The interface and mood selection work immediately.

## Add audio
Create an `audio` folder next to `index.html` and add your own legally usable MP3 files using the filenames referenced in `script.js`.

For a public/monetized website, use music you created, music you have permission to use, or properly licensed/royalty-free music.

## Publish for free
A simple option is GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository, e.g. `raabta-fm`.
3. Upload `index.html`, `style.css`, `script.js`, and the `audio` folder.
4. In repository Settings → Pages, choose deployment from the main branch.
5. GitHub will give you a free website URL.

This prototype does not upload or host copyrighted commercial songs.
